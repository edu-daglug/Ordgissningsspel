# Ordgissningsspel

2026-11-12
Idag har vi påbörjat ett nytt projekt som är ett ordningsprogram där man ska gissa sig fram till ett ord. Det fungerar som hänga gubbe där man har 10 felgissningar på sig där man måste gissa en bokstav i taget för att kunna bilda ett ord. Vi har kommit en bra bit på vägen, som att få ut själva grunden för programmet, men vi saknar vissa saker, som att sätta rätt gissning blad prickarna.
